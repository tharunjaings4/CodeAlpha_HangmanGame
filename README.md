# CodeAlpha Hangman Game

## About the Project
This is a simple word-guessing game developed using Python as part of my CodeAlpha Python Internship (October 2026).

The computer selects a secret word, and the player tries to guess it one letter at a time.

## Features
- Random word selection
- Hidden letters displayed as underscores
- Correct and incorrect guess tracking
- Input validation
- Detection of repeated guesses
- Win and lose conditions

## Technologies Used
- Python 3
- Python built-in `random` module

## How to Run
1. Install Python 3.
2. Download `hangman.py` from this repository.
3. Open a terminal in the folder containing the file.
4. Run the command:

   `python hangman.py`
